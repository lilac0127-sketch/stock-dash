# DOA 투자 인사이트 디자인

`index.html`을 브라우저에서 열면 디자인을 볼 수 있습니다. 외부 라이브러리나 API 키 없이 실행됩니다.

기존 Streamlit 앱에서도 로그인 후 `투자 인사이트 디자인` 화면으로 표시됩니다. `실제 데이터 분석`을 선택하면 기존 공시·시세·저장 기능을 사용합니다.

- 네이비 사이드바, 코발트 블루·코랄 포인트, 5개 KPI와 분석 카드.
- 반응형 레이아웃, 차트 기간 전환, 샘플 관심종목 추가, 지표 설명, 브라우저 내 일지 저장.
- 모든 숫자·캔들·거래량은 디자인 검토용 가상 데이터입니다. 실데이터 연동 화면이 아닙니다.
- 상단 KPI와 연간 실적 막대는 참조 이미지의 독립적인 예시를 재현합니다. 동일 기간 수치로 계산된 분석 결과가 아닙니다.
- 상단 입체 장식은 CSS로 재해석했으며 원본 이미지와 픽셀 단위로 같지는 않습니다.
- 메모는 localStorage에 저장되며 브라우저 저장소 제한 시 오류 안내를 표시합니다.
